Key Features
📁
Folder Hierarchyรองรับ Folder ลึกหลายชั้น พร้อม Confidentiality Level (HC / SC / NC / PC)
📄
File Upload / Downloadตรวจสอบ SHA256 Checksum + Virus Scan Status + Audit Log
🔐
Two-tier Access ControlAuthority-based (FolderAuthorityConfig) + ACL (FilePermission)
🗑️
Recycle BinSoft-delete พร้อม 30-day retention, restore, permanent delete พร้อม ownership guard
💾
Quota Managementตั้ง Quota ต่อ OrgUnit, Alert (Warning / Critical / Full), ขอเพิ่ม Quota workflow
📋
Folder Templateสร้าง Folder Structure จาก Template ทีเดียวทั้ง OrgUnit
🔗
File Sharingแชร์ไฟล์เฉพาะเจาะจง GRANT / DENY ต่อ User หรือ Role
⚡
Session CacheCache Folder list ระดับ Session เพื่อลด DB call
👤
Owner Deleteเจ้าของไฟล์ลบไฟล์ตัวเองได้ / เจ้าของรายการ RecycleBin ลบถาวรได้เฉพาะของตัวเอง

FileDocument

CMS.Domain/Models/FileDocument.cs
File Metadata Entity — maps to storage.FileDocument table
  • FileID, FileGUID, FolderID
  • OriginalFileName, StoredFileName, FileExtension, MimeType
  • FileSizeBytes, PhysicalPath, Checksum (SHA256)
  • VirusScanStatus: 0=Pending | 1=Clean | 2=Infected
  • FileStatus: 1=Active | 2=Archived | 3=Deleted
  • UploadedBy, UploadedDate
  • ArchivedBy, ArchivedDate
  • DeletedBy, DeletedDate
  • Version, IsHidden, HiddenBy, HiddenDate

FilePermission

File-level Permission Entry — GRANT/DENY ต่อ User/Role
  • FilePermissionID, FileID
  • PrincipalType, PrincipalID
  • CanRead, CanWrite, CanDelete, CanModify, CanFullControl
  • IsDeny (Deny เหนือกว่า Grant)
  • ExpiryDate
  • GrantedBy, GrantedDate
  • RevokedDate, RevokeReason
