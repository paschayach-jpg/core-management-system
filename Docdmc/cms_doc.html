01 — ภาพรวม

ระบบ CMS Import คืออะไร?

ระบบ CMS Import เป็นแพลตฟอร์มสำหรับจัดการเนื้อหา (Content Management)และนำเข้าข้อมูล (Data Import) ที่ออกแบบให้รองรับการทำงานขององค์กรได้อย่างยืดหยุ่น สามารถรับข้อมูลจากแหล่งภายนอกหลายรูปแบบ ประมวลผล ตรวจสอบความถูกต้อง และนำเข้าสู่ฐานข้อมูลหลักได้อย่างปลอดภัย

พัฒนาด้วย Clean Architecture บน .NET ทำให้ระบบมีความยืดหยุ่นสูง ดูแลรักษาง่าย และสามารถขยายความสามารถได้ในอนาคต

วัตถุประสงค์หลัก: ลดเวลาและความผิดพลาดในการนำเข้าข้อมูลด้วยมือ พร้อมเพิ่มความโปร่งใสในการจัดการเนื้อหาทั่วทั้งองค์กร
02 — ความสามารถ

ฟีเจอร์หลักของระบบ

📥

นำเข้าข้อมูลอัตโนมัติ

รองรับไฟล์ CSV, Excel, JSON และ XML พร้อม Validation ทุก field ก่อนบันทึก

✅

ตรวจสอบข้อมูล

ระบบตรวจสอบความถูกต้องของข้อมูลอัตโนมัติ แจ้งเตือนทันทีเมื่อพบข้อผิดพลาด

🔄

จัดการเนื้อหา

บริหารจัดการข้อมูลเนื้อหาได้หลายประเภทผ่าน Dashboard ที่ใช้งานง่าย

📊

รายงานผล

สรุปผลการนำเข้าข้อมูล บันทึก Log การทำงาน และส่งออกรายงานได้

🔐

ระบบสิทธิ์ผู้ใช้

กำหนดสิทธิ์การเข้าถึงแยกตาม Role พร้อมระบบ Authentication ที่ปลอดภัย

🔗

เชื่อมต่อระบบอื่น

มี API สำหรับเชื่อมต่อกับระบบภายนอกผ่าน RESTful Service

03 — สถาปัตยกรรม

โครงสร้างระบบ (Clean Architecture)

ระบบออกแบบตามหลัก Clean Architecture แบ่งชั้นการทำงานชัดเจน แต่ละชั้นมีหน้าที่เฉพาะ ทำให้แก้ไขและทดสอบได้ง่าย

1
CMS.Presentation
ส่วนติดต่อผู้ใช้งาน — Web UI, API Endpoints สำหรับ Client
Web Frontend REST API Views
2
CMS.Controllers
รับ Request และส่งต่อไปยัง Service Layer ที่เหมาะสม
HTTP Controllers Route Handling Request Mapping
3
CMS.Services
Business Logic ทั้งหมด รวมถึง Import Processing และ Validation
Business Logic Import Service Validation
4
CMS.Domain
โมเดลข้อมูลหลัก Entity และ Business Rules ที่ไม่ขึ้นกับ Framework
Entities Domain Models Business Rules
5
CMS.Infrastructure
ติดต่อระบบภายนอก ฐานข้อมูล ไฟล์ระบบ และ External Services
Database File System External APIs
6
CMS.Data
ชั้นเข้าถึงฐานข้อมูล Repository Pattern และ Data Context
Repository DbContext Migrations

05 — กระบวนการ

ขั้นตอนการนำเข้าข้อมูล

1

อัปโหลดไฟล์ต้นฉบับ

ผู้ใช้อัปโหลดไฟล์ข้อมูล (CSV, Excel, JSON) ผ่าน Web Interface หรือ API

2

ตรวจสอบรูปแบบไฟล์

ระบบตรวจสอบโครงสร้างและรูปแบบข้อมูลว่าตรงตาม Template ที่กำหนด

3

Validate ข้อมูลแต่ละแถว

ตรวจสอบความถูกต้องของแต่ละ record รวมถึง business rules และ constraints

4

Preview ผลลัพธ์

แสดงตัวอย่างข้อมูลที่จะนำเข้า พร้อมสรุปข้อผิดพลาดให้ผู้ใช้ยืนยัน

5

บันทึกลงฐานข้อมูล

นำเข้าข้อมูลที่ผ่านการตรวจสอบเข้าสู่ฐานข้อมูลแบบ Transaction-safe

6

สรุปผลและ Log

บันทึก Log การนำเข้า สร้างรายงานสรุป และแจ้งเตือนผู้เกี่ยวข้อง

🔌

API Gateway

RESTful API สำหรับเชื่อมต่อกับระบบภายนอก

📊

Dashboard

07 — ความคืบหน้า

สถานะการพัฒนา

โมดูล / ฟีเจอร์ สถานะ หมายเหตุ
Clean Architecture Setup สมบูรณ์ โครงสร้างโปรเจกต์ครบทุก Layer
Domain Models / Entities สมบูรณ์ กำหนด Entity หลักแล้ว
Database Layer (EF Core) กำลังพัฒนา Repository Pattern อยู่ระหว่างดำเนินการ
Import Service กำลังพัฒนา ตรรกะหลักอยู่ระหว่างสร้าง
REST API Controllers กำลังพัฒนา ออกแบบ Endpoint แล้ว
Frontend UI วางแผน อยู่ในขั้นออกแบบ
Unit Tests วางแผน โครงสร้าง Test Project พร้อมแล้ว
