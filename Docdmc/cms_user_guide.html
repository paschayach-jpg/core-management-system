การจัดการไฟล์และโฟลเดอร์
Document Management System
DMS

ระบบจัดเก็บและบริหารเอกสารกลางขององค์กร ใช้งานได้เหมือน Google Drive แต่มีการควบคุมสิทธิ์และความปลอดภัยสูงกว่า เหมาะสำหรับองค์กรที่ต้องการความโปร่งใสในการจัดการเอกสาร

📤
อัปโหลดไฟล์
อัปโหลดไฟล์ได้หลายไฟล์พร้อมกัน รองรับการอัปโหลดไฟล์ขนาดใหญ่แบบ Resume (เริ่มใหม่จากจุดที่ค้างได้) พร้อมสแกนไวรัสอัตโนมัติก่อนบันทึก
📥
ดาวน์โหลดไฟล์
ดาวน์โหลดไฟล์ได้ตามสิทธิ์ที่ได้รับ บางประเภทไฟล์ต้องขออนุมัติก่อนดาวน์โหลดเพื่อความปลอดภัย
📂
จัดการโฟลเดอร์
สร้าง เปลี่ยนชื่อ ย้าย คัดลอก ลบ และกู้คืนโฟลเดอร์ รองรับการย้ายโฟลเดอร์ทั้งโครงสร้างในครั้งเดียว
📋
Template โฟลเดอร์
สร้างโครงสร้างโฟลเดอร์มาตรฐานสำเร็จรูป นำไปใช้ซ้ำกับแผนกหรือโครงการใหม่ได้ทันที ไม่ต้องสร้างใหม่ทุกครั้ง
🗑️
ถังขยะ (Recycle Bin)
ไฟล์และโฟลเดอร์ที่ลบไปยังคงอยู่ในถังขยะ สามารถกู้คืนได้ก่อนที่จะลบถาวร ป้องกันการลบข้อมูลโดยไม่ตั้งใจ
💾
ตรวจสอบ Quota พื้นที่
ระบบติดตามพื้นที่จัดเก็บข้อมูลของแต่ละแผนก แสดงรายงานการใช้พื้นที่ และแจ้งเตือนเมื่อใกล้เต็ม
🔒
ระดับความลับ
กำหนดระดับความลับให้กับโฟลเดอร์ตั้งแต่เปิดเผยทั่วไปจนถึงลับชั้นสูง (Highly Confidential) เพื่อควบคุมการเข้าถึง
👁️
ซ่อน/แสดงไฟล์
ซ่อนไฟล์ที่ยังไม่พร้อมเผยแพร่ได้ชั่วคราว โดยที่ไฟล์ยังคงอยู่ในระบบ ผู้ดูแลยังเห็นอยู่
📊
รายงานพื้นที่จัดเก็บ
ดูรายงานสรุปการใช้พื้นที่จัดเก็บของทั้งองค์กร แยกตามแผนก พร้อมข้อมูลจำนวนไฟล์และขนาดรวม
🔗
การแชร์ไฟล์และโฟลเดอร์
Share Management
DMS

แชร์ไฟล์และโฟลเดอร์ได้ทั้งภายในและภายนอกองค์กร มีระบบควบคุมที่รัดกุม ทุกการแชร์จะถูกบันทึกและมีผู้อนุมัติ

🏢
แชร์ภายในองค์กร
ให้สิทธิ์เข้าถึงไฟล์แก่พนักงาน กลุ่มผู้ใช้ หรือแผนกอื่นๆ ภายในองค์กร กำหนดสิทธิ์ได้ว่าดูอย่างเดียว หรือดาวน์โหลดได้
🌐
แชร์ภายนอกองค์กร (Link)
สร้าง Link สำหรับแชร์ไฟล์ให้บุคคลภายนอก กำหนดรหัสผ่าน วันหมดอายุ (ไม่เกิน 90 วัน) และจำนวนครั้งที่ดาวน์โหลดได้สูงสุด
📋
ขออนุมัติก่อนแชร์
ผู้ใช้ทั่วไปต้องขออนุมัติจากผู้จัดการก่อนแชร์ภายนอก เพื่อป้องกันการเปิดเผยข้อมูลโดยไม่ได้รับอนุญาต
⏸️
หยุด/เปิดใช้ Link ได้ทันที
ผู้แชร์สามารถหยุดการใช้งาน Link ชั่วคราวหรือเปิดใช้งานใหม่ได้ทุกเมื่อ โดยไม่ต้องสร้าง Link ใหม่
📜
ดูประวัติการเข้าถึง
ดูได้ว่าใครเปิด Link วันที่เท่าไหร่ ดาวน์โหลดหรือแค่ดู สำเร็จหรือไม่ พร้อมสาเหตุที่ล้มเหลว
🚫
ยกเลิกสิทธิ์ได้ทันที
ยกเลิกการแชร์ทั้งภายในและภายนอกได้ทันที Link จะหมดอายุทันที ไม่สามารถเข้าถึงได้อีก
🔐
ระบบสิทธิ์การเข้าถึง
Permission & Access Control
DMS

ควบคุมว่าใครสามารถทำอะไรได้บ้างในระบบ กำหนดสิทธิ์ได้ละเอียดตั้งแต่ระดับโฟลเดอร์ถึงระดับไฟล์ รองรับสิทธิ์ตามบทบาทและตามบุคคล

👤
สิทธิ์รายบุคคล
กำหนดสิทธิ์ให้แต่ละคนแตกต่างกันได้ เช่น คนนี้ดูอย่างเดียว คนนั้นแก้ไขและลบได้
🏢
สิทธิ์ตามแผนก / กลุ่ม
ให้สิทธิ์เป็นกลุ่มตามแผนกหรือ Role ได้เลย ไม่ต้องตั้งทีละคน สะดวกเมื่อมีพนักงานใหม่เข้ามา
🔑
สิทธิ์ถ่ายทอดลงไฟล์
เมื่อตั้งสิทธิ์ที่โฟลเดอร์ ระบบจะนำสิทธิ์นั้นไปใช้กับไฟล์ทุกไฟล์ในโฟลเดอร์อัตโนมัติ ไม่ต้องตั้งทีละไฟล์
⚡
ตรวจสิทธิ์เร็ว
ระบบโหลดสิทธิ์ทั้งหมดมาไว้ใน Memory ตอน Login ทำให้การตรวจสอบสิทธิ์รวดเร็วมาก ไม่ต้องถาม Database ทุกครั้ง
✅
ระบบขออนุมัติ
Approval Management
DMS

ระบบขออนุมัติที่ครอบคลุมทุกการกระทำสำคัญในระบบ มีหลายขั้นตอน บันทึกผลทุกขั้น และส่งต่ออัตโนมัติเมื่อเกินเวลา

📝
ขออนุมัติสิทธิ์โฟลเดอร์
ผู้ใช้ทั่วไปต้องส่งคำขอเพื่อขอสิทธิ์เข้าถึงโฟลเดอร์ที่ตนเองยังไม่มีสิทธิ์ ผู้จัดการจะเห็นและอนุมัติหรือปฏิเสธ
💾
ขออนุมัติดาวน์โหลดไฟล์
ไฟล์ชั้นความลับสูงต้องขออนุมัติก่อนดาวน์โหลดได้ ระบบบันทึกว่าใครดาวน์โหลดเมื่อไหร่
🗑️
ขออนุมัติลบโฟลเดอร์
การลบโฟลเดอร์สำคัญต้องผ่านการอนุมัติ ป้องกันการลบข้อมูลโดยไม่ได้รับอนุญาต
⏰
Escalation อัตโนมัติ
เมื่อคำขออนุมัติค้างเกินเวลาที่กำหนด ระบบจะส่งต่อให้ผู้อนุมัติระดับถัดไปโดยอัตโนมัติ ไม่มีงานตกหล่น
↩️
ถอนคำขอได้
ผู้ขออนุมัติสามารถยกเลิกคำขอของตนเองก่อนที่จะได้รับการพิจารณาได้ทุกเมื่อ
โมดูลหลัก — KMS ฐานความรู้
🧠
ระบบจัดการความรู้ (KMS)
Knowledge Management System
KMS

ศูนย์รวมความรู้ขององค์กร พนักงานสามารถเขียน แก้ไข และค้นหาบทความความรู้ได้ รองรับการนำเข้าข้อมูลจาก Excel และมีระบบ Version ติดตามการแก้ไข

✏️
เขียนและแก้ไขบทความ
สร้างบทความความรู้ใหม่ แก้ไขเนื้อหา แนบไฟล์ประกอบ และสร้างลิงก์เชื่อมโยงระหว่างบทความ บทความมีรหัสเฉพาะ เช่น KB-2566-001
🔄
ระบบ Version ประวัติการแก้ไข
ทุกครั้งที่แก้ไขบทความระบบจะบันทึก Version เก่าไว้ สามารถดูประวัติการแก้ไขย้อนหลังได้ทั้งหมด
📤
เผยแพร่บทความ
บทความผ่านขั้นตอน Draft → ส่งตรวจสอบ → เผยแพร่ → เก็บถาวร มีผู้ตรวจสอบก่อนเผยแพร่จริง
📥
นำเข้าบทความจาก Excel
นำเข้าบทความความรู้จำนวนมากพร้อมกันจากไฟล์ Excel มีการตรวจสอบรูปแบบก่อนนำเข้า พร้อมรายงานผลสำเร็จ/ล้มเหลว
🔍
ค้นหาบทความ
ค้นหาบทความได้จากชื่อ รหัส หมวดหมู่ ประเภท หรือสถานะ รองรับการค้นหาขั้นสูงหลายเงื่อนไข
📊
Dashboard สถิติ
ดูสถิติบทความยอดนิยม บทความที่ถูกดูมากที่สุด ทิศทางการใช้งานรายเดือน และสถิติรวมของ KMS
โมดูลหลัก — WFE Workflow Engine
🔀
ระบบ Workflow อัตโนมัติ (WFE)
Workflow Engine
WFE

เครื่องมือสร้างกระบวนการอนุมัติและขั้นตอนการทำงานแบบอัตโนมัติ ออกแบบ Template ครั้งเดียว ใช้ได้ซ้ำๆ รองรับกำหนดเวลา SLA และการมอบหมายงาน

🗺️
ออกแบบ Template Workflow
ออกแบบขั้นตอนกระบวนการอนุมัติ กำหนดผู้รับผิดชอบแต่ละขั้น กำหนดเงื่อนไขที่จะเดินหน้าหรือย้อนกลับ และตั้งค่า Plugin เสริม
▶️
เริ่มกระบวนการ Workflow
สร้าง Workflow Instance จาก Template เพื่อใช้งานจริง ระบบจะสร้างงานให้ผู้เกี่ยวข้องแต่ละขั้นอัตโนมัติ
☑️
อนุมัติ/ปฏิเสธงาน
ผู้รับผิดชอบเห็นงานที่รอการอนุมัติของตน อนุมัติหรือปฏิเสธพร้อมระบุเหตุผล ระบบจะเดินหน้าขั้นตอนถัดไปอัตโนมัติ
📏
SLA — กำหนดเวลาแต่ละขั้น
กำหนดเวลาสูงสุดที่แต่ละขั้นตอนต้องเสร็จ ระบบตรวจสอบอัตโนมัติตลอดเวลา แจ้งเตือนเมื่อใกล้ครบกำหนด และรายงาน SLA Compliance
👥
มอบหมายงาน (Delegation)
เมื่อผู้รับผิดชอบลาหรือไม่อยู่ สามารถมอบหมายงานให้ผู้อื่นทำแทนได้ชั่วคราว พร้อมบันทึกว่าใครทำแทนใคร
⏸️
พัก/ดำเนินการต่อ Workflow
สามารถหยุด Workflow ชั่วคราวได้ เช่น รอเอกสารเพิ่มเติม และเปิดใช้งานต่อได้เมื่อพร้อม
🔒
เข้ารหัสและ PDPA
ข้อมูลใน Workflow สามารถเข้ารหัสได้ มีระบบตรวจสอบความสอดคล้องกับ PDPA และกำหนดนโยบายการเก็บรักษาข้อมูล
🔌
Plugin เสริม
เชื่อมต่อกับระบบอื่นได้ เช่น คำนวณ Premium ส่งรายงาน OIC ติดต่อ Risk Server ผ่าน Plugin ที่ติดตั้งเพิ่มได้
โมดูลหลัก — RGP บริหารโครงการ
📊
ระบบบริหารโครงการ (RGP)
Project Management
RGP

บริหารจัดการโครงการตั้งแต่เริ่มต้นจนเสร็จสิ้น ติดตามงาน วัดความคืบหน้า และจัดการเอกสารโครงการในที่เดียว

🗂️
จัดการโครงการ
สร้างโครงการใหม่จาก Template กำหนดสมาชิก บทบาท และสถานะโครงการได้หลายขั้น ตาม State Machine ที่กำหนด
✅
จัดการ Task
สร้างและมอบหมาย Task ให้สมาชิกในโครงการ ติดตามสถานะ วันครบกำหนด และความสำคัญของแต่ละงาน
📈
ติดตามความคืบหน้า
บันทึกและติดตามเปอร์เซ็นต์ความคืบหน้าของโครงการ ดูภาพรวมสถานะทุกโครงการในคราวเดียว
📁
เอกสารโครงการ
เก็บเอกสารทุกอย่างของโครงการไว้ในที่เดียว เชื่อมกับ DMS เพื่อควบคุมสิทธิ์และ Version ของเอกสาร
📋
Audit Trail โครงการ
บันทึกทุกการเปลี่ยนแปลงสำคัญในโครงการ ว่าใครทำอะไร เมื่อไหร่ เพื่อตรวจสอบย้อนหลังได้
ระบบสนับสนุน
👤
ผู้ใช้งานและโครงสร้างองค์กร
User & Organization Management
CORE

ระบบจัดการผู้ใช้และโครงสร้างองค์กร เชื่อมต่อกับ Active Directory ขององค์กร ไม่ต้องสร้าง Account ใหม่

🔑
Login ด้วย AD (Active Directory)
ใช้ Username/Password เดิมขององค์กร ไม่ต้องจำรหัสใหม่ รองรับการค้นหาพนักงานจากระบบ LDAP
🏗️
โครงสร้างองค์กร
จัดการ OrgUnit ตามสายบังคับบัญชาจริง สร้าง แก้ไข ย้าย หรือปิดใช้งานหน่วยงานได้ พร้อมเชื่อม Division กับ SubCommittee

ค้นหาพนักงาน

การแจ้งเตือนและ Audit Log
Notifications & Audit
CORE

ระบบแจ้งเตือนอัตโนมัติและบันทึกประวัติการใช้งานทุกอย่าง เพื่อความโปร่งใสและการตรวจสอบย้อนหลัง

📬
แจ้งเตือนงานที่รอดำเนินการ
เมื่อมีงานเข้ามาในคิว ระบบแจ้งเตือนผู้เกี่ยวข้องทันที ทั้งงานอนุมัติ Workflow และงาน SLA ที่ใกล้ครบกำหนด
🔗
แจ้งเตือนเมื่อได้รับสิทธิ์
เมื่อมีคนแชร์ไฟล์หรือให้สิทธิ์ ผู้ได้รับจะได้รับการแจ้งเตือนทันที รู้ว่ามีข้อมูลใหม่ที่เข้าถึงได้
📋
Audit Log ทุกการกระทำ
บันทึกทุกอย่างที่เกิดขึ้นในระบบ — ใครเข้าถึงไฟล์อะไร เมื่อไหร่ ทำอะไร ผลเป็นอย่างไร ไม่สามารถแก้ไขหรือลบบันทึกเหล่านี้ได้
⚡
แจ้งเตือนแบบ Async
ระบบแจ้งเตือนทำงานแบบไม่บล็อกการทำงานหลัก ส่งการแจ้งเตือนในคิวเบื้องหลัง ไม่ทำให้ระบบช้า
หมายเหตุ: ข้อมูลทั้งหมดในเอกสารนี้แปลมาจาก Source Code จริงของโปรแกรม (CMS.Services, CMS.Controllers, CMS.Domain) วิเคราะห์จากชื่อ Service, Interface, และ Method ที่นักพัฒนาเขียนไว้ในระบบ
