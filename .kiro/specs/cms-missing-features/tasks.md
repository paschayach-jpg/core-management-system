# Implementation Plan: cms-missing-features

## Overview

แผนการ implement ฟีเจอร์ที่ขาดอยู่ใน CMS WinForms C# .NET แบ่งเป็น 3 กลุ่มตาม design.md โดยแต่ละ task สร้างต่อยอดจาก task ก่อนหน้า และ wire เข้ากับ architecture MVP + Repository pattern ที่มีอยู่เดิม

## Notes

- Tasks ที่มี `*` เป็น optional สามารถข้ามได้เพื่อ MVP ที่เร็วขึ้น
- แต่ละ task อ้างอิง requirement เฉพาะเพื่อ traceability
- Checkpoint tasks ช่วย validate ความถูกต้องแบบ incremental
- Property tests ใช้ FsCheck (NuGet) รัน minimum 100 iterations ต่อ property
- Unit tests ครอบคลุม specific examples, edge cases, และ error messages
- ทุก property test ต้องมี comment: `// Feature: cms-missing-features, Property N: <property_text>`
