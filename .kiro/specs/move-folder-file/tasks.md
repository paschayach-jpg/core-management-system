แผนการ implement ฟีเจอร์ "ย้าย Folder และ File" (Move) ใน CMS WinForms C# .NET Framework 4.5 แบ่งเป็น 6 layer ตาม design.md โดยแต่ละ task สร้างต่อยอดจาก task ก่อนหน้า และ wire เข้ากับ architecture MVP + Repository pattern ที่มีอยู่เดิม

- [x] 3. Implement `FolderService.MoveFolder()`
  - [x] 3.1 Implement validation และ permission check ใน `MoveFolder()`
    - เพิ่ม method `MoveFolder(MoveFolderRequest request, UserContext user)` ใน `CMS.Services/FolderService.cs`
    - ตรวจสอบ null inputs: throw `ArgumentNullException` ถ้า request หรือ user เป็น null
    - Permission check: ถ้า `user.AppRole < 2` → throw `UnauthorizedAccessException("ต้องมีสิทธิ์ระดับ SrOfficer ขึ้นไป")`
    - ถ้า `user.AppRole < 4`: ตรวจ Write permission บน SourceFolder และ DestinationFolder ผ่าน `_permissionService.CheckPermission()`
    - _Requirements: 5.1, 5.2, 5.3, 5.4_
  - [x] 3.2 Implement circular reference check และ depth limit check
    - Load source และ destination ด้วย `_folderRepository.GetById()`
    - Circular reference: ถ้า `sourceFolderId == destinationParentFolderId` → throw `InvalidOperationException`
    - เรียก `_folderRepository.GetDescendants(sourceFolderId)` แล้วตรวจว่า destination ไม่อยู่ใน descendants
    - คำนวณ `projectedDepth = destination.FolderDepth + 1 + (maxDescendantDepth - source.FolderDepth)`
    - ถ้า `projectedDepth > MaxFolderDepth` → throw `InvalidOperationException` พร้อมระบุ depth และ MaxFolderDepth
    - _Requirements: 2.1, 2.2, 2.3, 3.1, 3.2_
  - [x] 3.3 Implement duplicate name check และ update source folder
    - เรียก `_folderRepository.GetChildren(destinationParentFolderId)` แล้วตรวจชื่อซ้ำ case-insensitive + trim
    - ถ้าซ้ำ → throw `InvalidOperationException` พร้อมระบุชื่อที่ซ้ำ
    - อัปเดต `source.ParentFolderID`, `source.FolderDepth`, `source.PhysicalPath`, `source.UpdatedBy`, `source.UpdatedDate`
    - เรียก `_folderRepository.Update(source)`
    - _Requirements: 4.1, 4.2, 4.3, 1.1_
  - [x] 3.4 Implement update descendants และ FileDocuments
    - คำนวณ `depthDelta = (destination.FolderDepth + 1) - source.FolderDepth เดิม`
    - วน loop descendants: อัปเดต `FolderDepth += depthDelta`, rebuild `PhysicalPath` ผ่าน `_networkDriveHelper.BuildPath()`, เรียก `_folderRepository.Update()`
    - รวบรวม `allFolderIds = [sourceFolderId] + descendants.Select(d => d.FolderID)`
    - วน loop แต่ละ folderId: เรียก `_fileDocumentRepository.GetByFolder()` แล้ว update `PhysicalPath` เฉพาะ file ที่ `FileStatus == 1`
    - _Requirements: 1.2, 1.3, 1.4_
  - [x] 3.5 Implement audit log สำหรับ MoveFolder
    - เรียก `_auditService.Log()` พร้อม `Action = "MoveFolder"`, `RecordID = sourceFolderId`, `OldValue = oldParentFolderId.ToString()`, `NewValue = destinationParentFolderId.ToString()`
    - _Requirements: 1.5, 11.7_
  - [ ]* 3.6 Write unit tests สำหรับ `FolderService.MoveFolder()`
    - ทดสอบ `AppRole < 2` → throws `UnauthorizedAccessException`
    - ทดสอบ self-move (source == destination) → throws `InvalidOperationException`
    - ทดสอบ destination เป็น descendant → throws `InvalidOperationException`
    - ทดสอบ projected depth เกิน 10 → throws `InvalidOperationException`
    - ทดสอบ duplicate name (case-insensitive) → throws `InvalidOperationException`
    - ทดสอบ soft-deleted sibling ไม่นับเป็น duplicate
    - ทดสอบ Admin (AppRole = 4) bypass permission check
    - _Requirements: 2.1, 2.2, 3.1, 4.1, 5.1, 5.4_

- [x] 4. Implement `FileService.MoveFiles()`
  - [x] 4.1 Implement validation และ permission check ใน `MoveFiles()`
    - เพิ่ม method `MoveFiles(MoveFileRequest request, UserContext user)` ใน `CMS.Services/FileService.cs`
    - ตรวจสอบ null inputs และ `request.FileIds == null || !request.FileIds.Any()` → throw `ArgumentException("ต้องระบุไฟล์อย่างน้อย 1 รายการ")`
    - Load destination folder ด้วย `_folderRepository.GetById()` ถ้าไม่พบ → throw `InvalidOperationException`
    - ถ้า `user.AppRole < 4`: ตรวจ Write permission บน DestinationFolder ผ่าน `_permissionService.CheckPermission()`
    - _Requirements: 6.4, 7.1, 7.3_
  - [x] 4.2 Implement loop update FileDocuments และ audit log
    - วน loop แต่ละ `fileId` ใน `request.FileIds`:
      - Load file ด้วย `_fileDocumentRepository.GetById()` ถ้าไม่พบ → throw `InvalidOperationException`
      - ถ้า `file.FileStatus != 1` → throw `InvalidOperationException` พร้อมระบุ FileID
      - ถ้า `user.AppRole < 4`: ตรวจ Write permission บน `file.FolderID` (source folder)
      - อัปเดต `file.FolderID = request.DestinationFolderId` และ rebuild `file.PhysicalPath` ผ่าน `_networkDriveHelper.BuildPath()`
      - เรียก `_fileDocumentRepository.Update(file)`
      - เรียก `_auditService.Log()` พร้อม `Action = "MoveFile"`, `OldValue = oldFolderId`, `NewValue = destinationFolderId`
    - _Requirements: 6.1, 6.2, 6.3, 6.5, 7.2_
  - [ ]* 4.3 Write unit tests สำหรับ `FileService.MoveFiles()`
    - ทดสอบ empty fileIds → throws `ArgumentException`
    - ทดสอบ file ที่ `FileStatus != 1` → throws `InvalidOperationException`
    - ทดสอบ ไม่มีสิทธิ์ Write บน DestinationFolder → throws `UnauthorizedAccessException`
    - ทดสอบ Admin bypass permission check
    - ทดสอบ audit log ถูกเรียกต่อ file
    - _Requirements: 6.4, 6.5, 7.1, 7.2, 7.3_

## Notes

- Tasks ที่มี `*` เป็น optional สามารถข้ามได้เพื่อ MVP ที่เร็วขึ้น
- แต่ละ task อ้างอิง requirement เฉพาะเพื่อ traceability
- Checkpoint tasks ช่วย validate ความถูกต้องแบบ incremental
- Property tests ใช้ FsCheck (NuGet) รัน minimum 100 iterations ต่อ property
- Unit tests ครอบคลุม specific examples, edge cases, และ error messages
- ทุก property test ต้องมี comment: `// Feature: move-folder-file, Property N: <property_text>`
- `IFolderService.GetDescendants()` ต้องเพิ่มใน interface ถ้ายังไม่มี (ปัจจุบัน `FolderRepository` มี `GetDescendants` แต่ `IFolderService` อาจยังไม่ expose)
