═══════════════════════════════════════════════════════════════════════════════
                         DATA FLOW SUMMARY
═══════════════════════════════════════════════════════════════════════════════

STEP 1 - Basic Info
─────────────────────
Input:   Template Name, Description
Flow:    Form → WizardState (TemplateName, Description)
Output:  Proceed to Step 2


STEP 2 - Workflow Flow Design
──────────────────────────────
Input:   DataGridView rows (Step Name, Action, Next Step)
Flow:    Form → Validate → Convert to WorkflowStepData list → WizardState.Steps
Output:  Proceed to Step 3


STEP 3 - Approval Configuration
────────────────────────────────
Input:   DataGridView rows (Step Name, Approver Group, Level)
Flow:    Form → Load from WizardState.Steps → Allow edit → Convert to
         WorkflowApproverData list → WizardState.Approvers
Output:  Proceed to Step 4


STEP 4 - Review & Publish
─────────────────────────
Input:   RadioButton selection (Draft/Publish)
Flow:    Form → Display summary from all previous steps →
         Call CreateTemplate service → Save to database →
         Return to list
Output:  ✅ Template saved & visible in grid
