# MOD-006: Knowledge Management System (KMS)
## Wireframe UI — ส่วนเพิ่มเติม: Tab Mapping รายการที่เกี่ยวข้อง
**Core Management System (CMS) | โครงการ 2511AL01 | Version 1.0**
**ออกแบบโดย: Sr. Systems Analyst | เมษายน 2569**

---

## ภาพรวม

เอกสารนี้เป็น **ส่วนเสริม** ของ `KMS_Wireframe_UI_v2.md` (ต้นฉบับ) โดยจะออกแบบเฉพาะ **Tab Panel ของ Mapping รายการที่เกี่ยวข้อง** ที่ปรากฏในสองจุดหลัก คือ:

1. **KMS-02: Knowledge Article Editor** — ส่วน "เอกสารแนบ & การเชื่อมโยง" (ด้านล่าง Editor)
2. **KMS-03: Knowledge Article Viewer** — Panel ขวามือ (ใต้ข้อมูลบทความ)

Tab ทั้ง 5 ที่ออกแบบในไฟล์นี้:
| Tab | ชื่อ | จุดที่ใช้ |
|-----|------|----------|
| Tab 1 | 📎 ไฟล์ที่แนบ | Editor + Viewer |
| Tab 2 | 🔗 ความรู้ที่เกี่ยวข้อง | Editor + Viewer |
| Tab 3 | ⚖️ เส้นงาน (Workflow) | Editor + Viewer |
| Tab 4 | 💻 โปรแกรมที่เกี่ยวข้อง | Editor + Viewer |
| Tab 5 | 📋 เอกสารที่เกี่ยวข้อง | Editor + Viewer |

### กลุ่มที่ 2 — Tab Mapping ที่มีอยู่แต่ออกแบบไม่ครบ

| รายการ | สถานะปัจจุบัน | สิ่งที่ขาด |
|--------|--------------|-----------|
| Tab ไฟล์แนบ (Editor) | มีโครงร่างเบื้องต้นใน KMS-02 | ขาด: Preview inline, Version ไฟล์, ข้อมูล CRAF Level, ขนาดรวม |
| Tab ความรู้ที่เกี่ยวข้อง | มีชื่อ Tab ใน KMS-02 แต่ไม่มี Content | ขาดทั้งหมด — เป็น Task หลักในเอกสารนี้ |
| Tab เส้นงาน | มีชื่อ Tab ใน KMS-02 แต่ไม่มี Content | ขาดทั้งหมด — เป็น Task หลักในเอกสารนี้ |
| Tab โปรแกรมที่เกี่ยวข้อง | มีชื่อ Tab ใน KMS-02 แต่ไม่มี Content | ขาดทั้งหมด — เป็น Task หลักในเอกสารนี้ |

**Column Detail:**
| Column | คำอธิบาย |
|--------|---------|
| ไอคอน | แสดงตามนามสกุลไฟล์ (📄 PDF, 📊 Excel, 📝 Word, 🖼️ รูป) |
| ชื่อไฟล์ | คลิกได้เพื่อ Preview (PDF/รูป) หรือ Download |
| ขนาด | แสดงเป็น KB หรือ MB |
| CRAF | ระดับความลับของไฟล์นั้น (สืบทอดจาก DMS หรือกำหนดเอง) |
| การจัดการ | [👁️ Preview] [🗑️ ลบออก] |

**Business Rules:**
- ไฟล์ที่มาจาก DMS → แสดง CRAF Level ตามที่กำหนดใน DMS (ไม่สามารถแก้ไขได้)
- ไฟล์ที่อัพโหลดใหม่ → สืบทอด CRAF Level จากบทความ (แก้ไขได้ก่อน Publish)
- ไฟล์ CRAF 1HC → เข้าถึงได้เฉพาะผู้ที่มีสิทธิ์ 1HC เท่านั้น
- ลบไฟล์แนบได้เฉพาะในสถานะ Draft/In Review
- หลัง Publish → ต้องสร้าง Version ใหม่จึงจะลบ/เพิ่มไฟล์ได้
