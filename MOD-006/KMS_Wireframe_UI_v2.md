## 1. ภาพรวม UI Architecture

```
┌─────────────────────────────────────────────────────────────────┐
│                    CMS Main Shell (WinForms MDI)                │
├──────────┬──────────────────────────────────────────────────────┤
│ Left Nav │                  Content Area (MDI Child)            │
│ (MOD     │  ┌────────────────────────────────────────────────┐  │
│ Menu)    │  │  KMS Module                                    │  │
│          │  │  ┌──────────┬───────────────────────────────┐  │  │
│📚KMS     │  │  │ Category │  Article List / Editor /      │  │  │
│          │  │  │ Tree     │  Viewer / Dashboard           │  │  │
│          │  │  │          │                               │  │  │
│          │  │  └──────────┴───────────────────────────────┘  │  │
│          │  └────────────────────────────────────────────────┘  │
└──────────┴──────────────────────────────────────────────────────┘

Navigation Flow (Article):
KMS-01 (List) → [คลิกบทความ] → KMS-03 (Viewer)
KMS-01 (List) → [+ สร้าง]    → KMS-02 (Editor)
KMS-01 (List) → [ค้นหา]      → KMS-04 (Search)
KMS-03 (View) → [✏️ แก้ไข]   → KMS-02 (Editor)
KMS-03 (View) → [History]    → KMS-09 (Version)
KMS-03 (View) → [Comments]   → KMS-12 (Rating)

Navigation Flow (Wiki):
KMS-16 (Spaces) → [เข้า Space]  → KMS-17 (Page Tree)
KMS-17 (Tree)   → [คลิกหน้า]   → KMS-18 (Wiki Viewer)
KMS-17 (Tree)   → [+ หน้าใหม่] → KMS-20 (Template Gallery) → KMS-19 (Wiki Editor)
KMS-18 (View)   → [✏️ แก้ไข]   → KMS-19 (Wiki Editor)
KMS-19 (Edit)   → [🔗 แทรก Link] → KMS-21 (Link Browser)
KMS-18 (View)   → [History]    → KMS-22 (Wiki Diff)

Navigation Flow (Admin):
Manager → KMS-23 (Approval Queue)
Admin   → KMS-24 (Reports Dashboard)
Admin   → KMS-25 (Tag Management)
```
