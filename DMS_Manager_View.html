Priority 1  ·  STRUCTURE

โครงสร้างที่ชัดเจน

แผนกมี Folder อะไรบ้าง ระดับความลับชัดเจน ไม่มีการสร้าง Folder มั่วซั่ว

  • Confidentiality Level HC / SC / NC / PC
  • ลำดับชั้น Folder ชัดเจน ดูได้ทันที
  • HC Folder ต้องขออนุมัติก่อนสร้าง
  • Archive เมื่อเอกสารหมดอายุใช้งาน
🔐
Priority 2  ·  CONTROL

กำหนดสิทธิ์เองได้

Manager กำหนดว่าใครเข้าถึง Folder/File ได้ระดับไหน — ไม่ต้องรอ IT

  • Permission Authority ตาม Position/แผนก
  • ACL ระดับ File — GRANT หรือ DENY เฉพาะ User
  • Effective Permission คำนวณอัตโนมัติ
  • ซ่อนไฟล์ชั่วคราวโดยไม่ต้องลบ
✅
Priority 3  ·  OVERSIGHT

มองเห็น + ตรวจสอบได้

รู้ทันทีว่าใครลบอะไร ใครขออะไร Quota ใช้ไปเท่าไหร่

  • Approval Inbox — รออนุมัติทั้งหมดในที่เดียว
  • Recycle Bin แสดง "ลบโดย" ครบถ้วน
  • Storage Quota report ต่อแผนก
  • Audit Trail ทุก action มี timestamp

Narrative Flow สำหรับ Manager

เรียง story 4 ขั้น ให้ Manager เห็นคุณค่าตั้งแต่ต้นจนจบ

1

โครงสร้างชัด — ไม่มี Folder ลักไก่

แผนกมี Root Folder 4 ระดับ (HC→PC) ระบบบังคับขออนุมัติก่อนสร้าง HC Folder — Manager ไม่ต้องกังวลว่าจะมีเอกสารลับหลุดไปผิด Folder

Folder Hierarchy HC = ต้องอนุมัติ 4 Confidentiality Levels
2

กำหนดสิทธิ์ได้เอง — ไม่ต้องรอ IT

Manager ตั้ง Permission ได้โดยตรง ทั้งระดับ Folder (Authority by Position/แผนก) และระดับ File (ACL — GRANT/DENY เฉพาะ User) พร้อมกำหนดวันหมดอายุสิทธิ์

FolderAuthorityConfig File ACL ExpiryDate GRANT / DENY
3

อนุมัติไม่หาย — มี Inbox + Escalation

คำขอทุกอย่าง (สร้าง HC Folder, Download ไฟล์ลับ, เพิ่ม Quota) รวมอยู่ใน Inbox ของ Manager อนุมัติ/ปฏิเสธได้ในคลิกเดียว ถ้าไม่ดำเนินการภายในเวลากำหนด ระบบ Escalate อัตโนมัติ

Approval Inbox Escalation Quota Request Approve / Reject
4

ตรวจสอบย้อนหลังได้ทุก action

ใครลบอะไร เมื่อไหร่ — ดูได้จาก Recycle Bin (แสดง "ลบโดย" ทุกรายการ) ไม่มีการสูญหายเงียบ ลบถาวรได้เฉพาะเจ้าของรายการ หรือ Admin เท่านั้น
